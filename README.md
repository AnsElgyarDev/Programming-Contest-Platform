# 🏆 Programming Contest Platform - Backend API

A robust, scalable RESTful API backend designed for competitive programming and online judge systems. Built using **.NET 8 / ASP.NET Core Minimal APIs** following **Clean Architecture** principles.

### ✨ Key Features:
* **Authentication & Security:** Secure user registration & login powered by **BCrypt** hashing and unique constraint protections.
* **Architecture:** Structured with Clean Architecture (Domain, Application, Infrastructure, API) for maintainability and testability.
* **Data Access:** Entity Framework Core with Fluent API configurations, migrations, and index optimizations.
* **Minimal APIs & TypedResults:** Strongly-typed endpoints with explicit return types for high-performance routing and seamless Swagger/OpenAPI documentation.

### 🛠️ Tech Stack:
* **Framework:** .NET 8 (ASP.NET Core Minimal APIs)
* **ORM:** Entity Framework Core
* **Database:** SQL Server
* **Security:** BCrypt.Net-Next
* **Tools:** Swagger UI / Postman
